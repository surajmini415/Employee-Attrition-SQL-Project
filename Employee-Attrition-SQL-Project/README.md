# Employee Attrition Analysis using SQL

## Project Overview
This project analyzes employee attrition data using MySQL to identify factors affecting employee turnover.

## Dataset
IBM HR Analytics Employee Attrition Dataset

## SQL Analysis Performed

1. Total Employee Count
2. Attrition Distribution
3. Attrition by Department
4. Average Income by Job Role
5. Overtime vs Attrition Analysis
6. Average Age by Attrition

## Key Insights

- Total Employees: 1470
- Research & Development had the highest attrition.
- Employees working overtime showed higher attrition.
- Managers had the highest average monthly income.
- Employees who left were younger on average.

## Tools Used

- MySQL
- MySQL Workbench
- SQL
